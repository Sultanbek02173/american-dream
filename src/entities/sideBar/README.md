# Адаптивный SideBar

## Описание

Адаптивный сайдбар с поддержкой мобильных устройств, планшетов и десктопов.

## Особенности

### Десктоп (1400px+)

- Полноразмерный сайдбар (134px)
- Всегда видимый
- Стандартная анимация

### Планшет (768px - 1400px)

- Уменьшенный сайдбар (100px)
- Частично скрыт (transform: translateX(-50px))
- Адаптированные размеры иконок

### Мобильные устройства (до 768px)

- Полноэкранный сайдбар
- Гамбургер-меню для открытия/закрытия
- Оверлей с размытием фона
- Автоматическое закрытие при смене роута

## Компоненты

### SideBar.jsx

Основной компонент сайдбара с поддержкой:

- Адаптивного поведения
- Мобильного меню
- Анимаций Framer Motion

### useMobileMenu.js

Хук для управления состоянием мобильного меню:

- Определение размера экрана
- Управление открытием/закрытием меню
- Автоматическое закрытие при изменении размера экрана

## Стили

### sideBar.scss

- Адаптивные медиа-запросы
- Стили для гамбургер-меню
- Оверлей для мобильной версии
- Плавные переходы

### media.scss

- Дополнительные медиа-запросы
- Скрытие гамбургер-меню на больших экранах

## Использование

```jsx
import { SideBar } from './entities/sideBar/SideBar';

const routes = [
  { id: 1, link: '/dashboard', img: '/icons/dashboard.svg' },
  { id: 2, link: '/students', img: '/icons/students.svg' },
  // ...
];

<SideBar routes={routes} />;
```

## Брейкпоинты

- `lg` (1400px+): Десктоп
- `xl` (768px - 1400px): Планшет
- `md` (до 768px): Мобильные устройства

## Анимации

- Плавное появление/исчезновение сайдбара
- Анимированная кнопка гамбургер-меню
- Плавные переходы между состояниями
- Активный индикатор с spring-анимацией
